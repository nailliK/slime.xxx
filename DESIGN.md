# Design System

## Overview
An experimental, "vectorheart", early-2000s inspired music showcase website for an electronic music artist. 

## Colors
- **Primary** (#29AA35): CTAs, active states, key interactive elements
- **Secondary** (#2286EA): Supporting UI, chips, secondary actions
- **Surface** (#222222): Page backgrounds
- **On-surface** (#F5F5F5): Primary text on dark backgrounds
- **Error** (#f5989d): Validation errors, destructive actions

## Typography
Dogica is a bitmapped and monospaced pixel font based off of a 8x8 grid. All text sizing needs to follow 8px increments

- **Headlines**: Dogica Pixel Bold (24px)
- **Body**: Dogica Pixel (16px)
- **Labels**: Dogica Pixel Bold (16px)

## Do's and Don'ts
- Do use the primary color sparingly, only for the most important action
- Don't mix rounded and sharp corners in the same view
- Do maintain 4:1 contrast ratio for all text
- Do experiment with faux wireframe-style 3D renderings, lots of icons, and other vectorheart-style composition elements
